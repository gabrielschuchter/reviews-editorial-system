# Catálogo de regressão

| Caso | Risco protegido |
| --- | --- |
| `EV-FAC-*` | número sem claim ou divergente |
| `EV-COR-001` | vazamento de holdout |
| `EV-AI-001` | token de ferramenta no texto |
| `EV-INF-001` | desfecho substituto como benefício clínico |
| `EV-TAB-001` | recomendação sem contexto autossuficiente |
