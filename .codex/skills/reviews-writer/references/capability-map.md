# Mapa de capacidades

`reviews-writer` conserva o ponto de entrada histórico. Ele coordena sete capacidades especializadas e impede que qualquer uma substitua a autoridade da fonte ou do editor humano.

| Capacidade | Artefato principal | Não faz |
| --- | --- | --- |
| Source provenance | `normalized/source-roles.json`, claim ledger | Conclusão clínica |
| Scientific appraisal | julgamentos e limites de inferência | Redação final |
| Editorial brief | `planning/editorial-brief.yaml` | Inventar contexto |
| Edition writing | candidata com claims autorizados | Aprovar a edição |
| Audit | relatório de findings | Corrigir silenciosamente |
| Feedback learning | padrão candidato + teste | Promover regra automaticamente |
| Document presentation | tabela/DOCX/render report | Alterar conteúdo científico |
