# Evidência humana para orquestração

O registro de origem está em
[reviews-human-style-evidence.json](../../../../corpus/reviews-human-style-evidence.json).
Ele deriva de sete publicações finais, sete auditorias e comparações humanas
reais, mantendo IDs, limites e trechos anonimizados.

## Aplicação no plano

Use REV-STYLE-001 para garantir que planning e framing questionem a decisão,
problema ou limite de aplicação, sem impor fórmula única de abertura. Use
REV-STYLE-004 para incluir anti-IA, humanizer e audit quando o fecho parece
recapitular. Use REV-STYLE-006 para encaminhar correções humanas a aprendizado
como hipótese, nunca como promoção automática.

## Limites

O material é referência B, não padrão final. Não use essa evidência para sustentar
claims clínicos, escolher uma frase-modelo, recuperar holdout ou ignorar source
roles e appraisal. O orquestrador registra onde ela influenciou uma escolha de
capability.
